Tools & approvals

The agent doesn't just talk — it acts. Every tool call is visible as a live activity chip in the chat: what ran, its arguments, its result and its status (running → done / denied / error). Tap a chip to inspect the raw JSON.

The approval gate

When the agent calls a 🛡️ sensitive tool, the turn pauses and an inline card appears with three choices:

  • Allow once — approve just this call.
  • Always (session) — approve this tool for the rest of the current session. The agent stops asking. Close the app or start a new session and the gate re-arms.
  • Deny — the call is refused; the agent receives {"denied": true} and adapts instead of failing.
Design rule: reading and remembering is free; destroying or committing your memory always asks. You can also deny mid-flight — nothing executes before you decide.
