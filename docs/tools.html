The toolbox & the gate

The dragon doesn't just talk — it calls tools. Every call shows up as a live chip in the chat: name, arguments, result and status. Tap a chip to read the raw JSON.

No filesystem, no contacts, no microphone. The mobile toolbox is deliberately narrow — memory, time, math, device basics.

gateHow approvals work

When a 🛡 tool fires, the turn pauses mid-flight and an inline card appears with three choices:

  • Allow once — approve this call only.
  • Always (session) — approve the tool for the rest of this session. Closing the app or starting a new session re-arms the gate.
  • Deny — the call never runs; the dragon receives {"denied": true} and adapts instead of erroring.
you      forget everything about my sister
dragon   forget_memory { "id": "a3f9" }   ← paused
         [ Deny ]  [ Always (session) ]  [ Allow once ]

The rule of thumb: remembering is free; destroying or committing memory always asks.

flightWatching a turn happen

With deep thinking on, reasoning streams into the Thinking pill above the answer. Tool chips tick from running to done / denied / error in real time, and each answer carries its token count. Together it's a flight recorder for every turn — tap anything to inspect it.
