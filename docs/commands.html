Chat commands

Type these straight into the message box — they run locally, no tokens spent.

CommandAction
/newStart a fresh session
/remember <fact>Pin a long-term fact (into the active memory engine)
/forget <id>Delete a fact / bullet by id prefix
/memoriesOpen the memory manager
/clearWipe all facts & bullets (MEMORY.md is kept)
/helpList commands inside the chat

Keyboard-free equivalents

  • New chat — the ✎ button in the top bar.
  • Switch model — tap the model chip in the top bar.
  • Memories — Settings → Facts, rules & outline.
  • Sessions — Settings → Sessions; tap one to resume it verbatim.

Tips

  • Long-press a fact in the memory manager to forget it; long-press an outline bullet to delete it.
  • Tap any answer's copy icon to grab clean markdown; code blocks have their own copy button with the language label.
  • Tap the Thinking pill to audit the model's reasoning before trusting the answer.
