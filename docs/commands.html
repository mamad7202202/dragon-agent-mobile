docs / commands

Slash commands

Type these in the message box. They run locally — no tokens are spent.

localThe list

commandwhat happens
/newStarts a fresh session
/remember <fact>Pins a fact into the active memory engine
/forget <id>Deletes a fact or bullet by id prefix
/memoriesOpens the memory manager
/clearWipes facts and bullets — MEMORY.md is kept
/helpPrints this list in the chat

tapSame things without typing

  • New chat — the ✎ button in the top bar.
  • Switch model — tap the model chip in the top bar.
  • Memory — Settings → Facts, rules & outline. Long-press an entry there to forget it.
  • Sessions — Settings → Sessions; tap one to resume it exactly where you left off.

tipsSmall things worth knowing

  • The copy icon on an answer grabs clean markdown; code blocks have their own copy button with the language label.
  • Tap the Thinking pill to audit the reasoning before you trust the answer.
  • Answers carry a small token badge when the provider reports usage — useful for spotting when a model is rambling.
