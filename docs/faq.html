Questions, answered

keysWhere does my API key go?

Into the app's private storage on your phone. Requests go straight to the provider you picked. Dragon has no backend, no analytics, no telemetry.

tokensDoes memory cost extra tokens?

Yes — a little, on purpose. Hybrid mode injects up to six scored facts. Outline mode injects a compact outline of a few hundred tokens no matter how much it knows. That trade is exactly why outline mode exists: maximum recall per token.

privacyCan it read my files or mic?

No. The mobile toolbox is memory, time, math and device basics. Destructive memory actions pause and ask you first — and you can deny mid-flight.

thinkWhich models support deep thinking?

Anthropic Claude (native thinking budgets), OpenAI reasoning models, and Gemini 2.5+ through the OpenAI-compatible layer. OpenRouter routes the effort setting to whatever the underlying model supports. Models without reasoning ignore it safely.

searchWhy is web search off for my provider?

Native search exists for OpenRouter (:online) and Anthropic (server-side web_search). Others show the toggle as unavailable rather than pretending to search.

lanOllama won't connect

On a phone, localhost is the phone. Use your computer's LAN IP — http://192.168.1.10:11434/v1 — keep both devices on the same network, and make the server listen on all interfaces (OLLAMA_HOST=0.0.0.0).

bugsHow do I report a bug?

Open an issue at GitHub Issues. If you hit the in-app error screen, copy the message it shows — it pinpoints the failure.

ossIs it really open source?

MIT — the app, the CI, and this site. The desktop sibling lives at mamad7202202/dragon-agent.
