FAQ

Where does my API key go?

Into your device's private storage only. Requests go directly from your phone to the provider you chose. The app has no backend, no analytics, no telemetry.

Does memory cost extra tokens?

Yes — a small amount per message, by design. Hybrid mode injects up to 6 scored facts; Outline mode injects a compact outline (typically a few hundred tokens) regardless of how much you know. That's exactly why Outline mode exists: maximum recall per token.

Can the agent access my files, contacts or microphone?

No. The mobile toolbox deliberately excludes filesystem and shell access. Tools cover memory, time, math and device basics — and destructive memory actions require your explicit approval.

Which models support deep thinking?

Anthropic Claude (native thinking budgets), OpenAI reasoning models, and Gemini 2.5+ via the OpenAI-compat layer. OpenRouter routes reasoning_effort to whatever the underlying model supports. Models without reasoning ignore the setting safely.

Web search doesn't work on my provider?

Native search is wired for OpenRouter (:online) and Anthropic (server-side web_search tool). Other providers show the toggle as unavailable instead of silently pretending to search.

Ollama / LM Studio can't connect

On a phone, localhost is the phone itself. Use your PC's LAN IP (e.g. http://192.168.1.10:11434/v1), make sure both devices are on the same network and the server binds to 0.0.0.0, not just loopback.

How do I report a bug?

Open an issue at GitHub Issues. If you see the in-app red error screen, copy the message it shows — it pinpoints the failure.

Is it really open source?

MIT — everything, including this site. The desktop sibling lives at mamad7202202/dragon-agent.
