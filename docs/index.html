Why Dragon Agent

Most chat apps forget you the moment you close them. Dragon ports the desktop dragon-agent memory architecture to your pocket — and wraps it in a liquid-glass UI.

🧠

Hybrid memory

Scored facts, procedural MEMORY.md rules, resumable sessions and automatic compaction — no vector database, works fully offline.

🗺️

Outline memory

A second engine: hierarchical sections & one-line bullets the model recalls in a few hundred tokens. Ultra-efficient, still complete.

🔑

Bring your own key

Google, OpenRouter, OpenAI, Anthropic, Groq, DeepSeek, Ollama / LM Studio over LAN, or any OpenAI-compatible endpoint.

🛠️

Real tools

The agent saves & organises memory on its own, does exact math, reads the clock & device — with live activity chips and approval gates for sensitive actions.

💭

Deep thinking

Reasoning-effort control (Off → Deep) with a collapsible thought process, live web search, and token usage per message.

⚡

Self-updating

Checks GitHub releases on connect and installs updates over the current version — one tap, no reinstalls.

Ready in under a minute

Install the APK, pick a provider, paste a key, choose a model. That's it — the dragon handles the rest.
