docs / memory

Two engines, one memory

Both engines run on-device, work offline, and are injected into every turn. Switch between them in Settings — both stores stay on disk, so switching is never destructive.

engineTry the recall formula

This is the actual scoring Dragon runs before every turn in hybrid mode. Type a query — the six facts below are what "the dragon" knows:

recall lab k = 3 · decay 14d · cosine over tokens
score = cosine(q, fact) × (0.55 + 0.45·importance) × (0.7 + 0.3·recency)   recency = 1 / (1 + age_days / 14)

Sage rows are the top-3 injected into the prompt. Change the query to “what tea does he drink” or “what is he building” and watch the ranking move. Importance and age matter as much as word overlap — that's why “tea, no sugar” beats newer-but-irrelevant facts.

engineHybrid — scored facts

The classic engine. Facts live in facts.json; each turn the top-k are recalled by the formula above and injected. The dragon saves new facts itself via save_memory when it notices something durable, and deduplicates near-identical ones on write.

engineOutline — the infographic

The same knowledge, restructured for cheap recall: named sections of self-contained one-line bullets. The whole outline is injected every turn — a few hundred tokens regardless of how much the dragon knows:

[MEMORY OUTLINE]
profile:      Name is Mamad; Lives in Tehran;
preferences:  Answers in Persian; Dark UI everywhere;
projects:     Dragon Agent — Rust desktop agent; Mobile port in Flutter;
people:       Sister called Sara;
goals:        Ship the Play Store release this year;
  • memory_write(section, bullets) — upserts one-liners (≤140 chars). Identical or near-identical bullets refresh, never pile up.
  • memory_delete(id | section) — clears stale entries, behind your approval.
  • When an outline grows too large, sections are ranked against your message and the least relevant ones drop first — never mid-thought.

Anything too rich for a bullet still belongs in MEMORY.md rules or the session transcript. Outline mode doesn't replace those.

rulesProcedural — MEMORY.md

Standing instructions loaded in both engines, every turn. Edit them under Memories → Rules, or let the dragon append via remember_rule (it asks first):

- Always answer in Persian
- My timezone is +3:30
- Never suggest cloud services I didn't ask about

episodicSessions

Every conversation is a resumable transcript on device. Reopen any of them from Settings → Sessions. Long ones fold their oldest turns into a dense summary once they pass the compaction threshold, so the context window never overflows.
