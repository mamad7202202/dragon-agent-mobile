docs / getting started

From APK to first conversation

Four steps, about a minute. You need the APK and one API key from any provider.

01Install the build

Download from the latest release and sideload it:

  • Android — Dragon-Agent-android-arm64.apk fits most phones. The -universal build covers every other ABI.
  • iOS — Dragon-Agent-iOS-unsigned.ipa, installed with Sideloadly or AltStore, or signed yourself in Xcode.

Every push to main produces fresh builds in CI. You never compile anything locally.

02Pick a provider

First launch opens a three-step wizard. Choose where the intelligence comes from — the full list lives on the providers page. Good first picks:

  • Google AI Studio — free keys, Gemini models.
  • OpenRouter — one key, 400+ models.
  • Ollama / LM Studio — your own machine, no cloud.

03Paste the key

The base URL fills itself in. Your key is stored in the app's private storage and sent only to that provider — Dragon has no server of its own.

Local models on a phone: localhost is the phone itself. Use your computer's LAN address instead, like http://192.168.1.10:11434/v1 for Ollama, and make sure the server listens on all interfaces.

04Choose a model and talk

Suggested models appear as chips; type any model id you prefer. After the wizard you land in the chat. Try:

"Remember that my sister's name is Sara"

You'll see the dragon call save_memory on its own. Ask again tomorrow — on a new phone, even — and it recalls the fact. That's the whole point.

Make it yours

  • Appearance — light, dark or system theme.
  • Intelligence — deep thinking, web search, temperature.
  • Memory — hybrid or outline engine, switchable anytime.
  • Tap the model chip in the top bar to change models mid-session.
