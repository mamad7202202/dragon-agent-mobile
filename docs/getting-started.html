Getting started

From download to your first conversation in about a minute.

1 · Install

Grab the newest build straight from CI — nothing is compiled on your machine:

  • Android → open the latest release and download Dragon-Agent-android-arm64.apk (or -universal for older/rare devices), then sideload it.
  • iOS → download Dragon-Agent-iOS-unsigned.ipa and install it with Sideloadly or AltStore, or sign it yourself in Xcode.

2 · Pick a provider

On first launch the setup wizard walks you through three steps. Step one is choosing where your intelligence comes from:

  • Google AI Studio — generous free tier, great default.
  • OpenRouter — 400+ models behind one key.
  • OpenAI · Anthropic · Groq · DeepSeek — first-party APIs.
  • Ollama / LM Studio — local models, fully offline (see below).
  • Custom — any OpenAI-compatible endpoint.

Full details and key links live on the Providers page.

3 · Connect

The base URL is pre-filled for every preset — you only paste your API key. Keys are stored exclusively on your device and sent directly to the provider; Dragon has no backend and no telemetry.

Local models: your phone can't reach localhost of your PC. Replace it with your computer's LAN IP, e.g. http://192.168.1.10:11434/v1 for Ollama. The app is allowed to use cleartext HTTP for exactly this reason.

4 · Pick a model & start

Suggested models appear as chips per provider, or type any model id. After the wizard you land in the chat — try one of the starter prompts, or say “Remember that my sister's name is Sara” and watch the memory tools fire.

5 · Make it yours

  • Settings → Appearance — light / dark / system theme.
  • Settings → Intelligence — deep-thinking level, web search, temperature.
  • Settings → Memory — choose the Hybrid or Outline engine.
  • Tap the model chip in the top bar to switch models mid-session.
